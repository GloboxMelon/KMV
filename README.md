# KMV

**What is KMV?**
It's a new movie file format **(not really)** called KMV (Kitten MoVie).

**How it works?**

KMV format is like this:
- MAGIC (KMOVIE)
- Terminators (10 2E bytes)
- MP4 data

## This repository contains KAD (Kitten AuDio)

**What is KAD?**
It's a new audio file format **(not really)** called KAD.

**How it works?**

KAD format is like this:
- MAGIC (KAUDIO)
- Terminators (10 2E bytes)
- File format
- FLAC/MP3/WAV/MIDI data
